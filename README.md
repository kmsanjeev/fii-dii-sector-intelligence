# fii-dii-sector-intelligence
The objective is to create an institutional-flow intelligence engine that continuously monitors NSE sectors and their constituent stocks, tracks money-flow behavior, identifies possible institutional activity, and generates actionable insights.

## VEDA relationship (current transition)

This repository remains the authoritative market-intelligence provider and
current host of its working runtime. VEDA's universal product and ecosystem
documentation authority is `D:\Projects\VEDA`; no source or data migration is
claimed. The provider boundary and transition record are documented in
`docs/governance/VEDA-INDEPENDENCE-TRANSITION.md`.
