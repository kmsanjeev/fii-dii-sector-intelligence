# Prioritisation Model

Prioritisation is qualitative and evidence-based. Review each candidate against:

- user value and response-quality impact;
- foundation/calculation/knowledge readiness;
- provenance and dependency completeness;
- reuse potential and implementation risk;
- predictive and empirical compatibility;
- safety and production boundary.

Priority tiers: **READY CANDIDATE** requires complete dependencies and a clear scope; **RESEARCH/INPUT REQUIRED** requires evidence first; **DEFERRED** is captured but intentionally not authorized; **RESERVED** has an ID but no scope.
