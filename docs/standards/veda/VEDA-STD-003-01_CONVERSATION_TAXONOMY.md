# Conversation Taxonomy

The extensible V1 taxonomy contains ten initial types:

| Type | Response tendency |
|---|---|
| SMALL_TALK | Light social rapport; avoid unnecessary RAG |
| HEART_TO_HEART | Warm, attentive, non-mechanical support |
| PILLOW_TALK | Affectionate private context without automatic sexualization |
| SWEET_TALK | Warm but bounded; do not infer manipulation without evidence |
| PEP_TALK | Encouraging and action-oriented without cliches |
| REAL_TALK | Candid and proportionate |
| STRAIGHT_TALK | Direct, concise, fact-focused |
| TRASH_TALK | Distinguish playful competition from hostility and de-escalate |
| DOUBLE_TALK | Separate literal language from possible evasion/deferral |
| SHOP_TALK | Domain-aware explanation adapted to proficiency |

Future candidates include sarcasm, banter, debate, negotiation, mentoring,
teaching, storytelling, humour, flirting, consoling, venting, brainstorming,
interview, diplomacy, and professional briefing.

Conversation mode may change across turns. The analyzer records a transition
when recent context moves from rapport to disclosure or another type.
