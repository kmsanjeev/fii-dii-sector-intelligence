# Capability Permission Model

Capabilities conceptually expose research, calculation, rule evaluation, experimental prediction, shadow, backtesting, ML, RAG, production interpretation, and real-world action permissions.

`PRODUCTION_RESTRICTED`, `VALIDATION_REQUIRED`, `DEPENDENCY_BLOCKED`, `OUT_OF_SCOPE_MEDICAL`, and `PROHIBITED_CERTAINTY` must not be interpreted as research suppression unless execution is technically impossible.
