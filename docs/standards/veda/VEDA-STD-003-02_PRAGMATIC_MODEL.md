# Pragmatic Model

The internal context contract covers language, code switching, conversation
type, literal and pragmatic intent, emotion, tone, formality, directness,
relationship context, humour, sarcasm, persuasion, conflict, domain,
proficiency, expressions, and response strategy.

Inferences are confidence-bearing and non-diagnostic. `POSSIBLE_SARCASM`,
`POSSIBLE_PERSUASION`, and `POSSIBLE_EVASION` are preferred to unsupported
certainty. For double talk, VEDA retains the literal statement and a possible
pragmatic reading without calling the speaker dishonest.

Response strategies include LIGHT_SOCIAL, SUPPORTIVE, DIRECT_FACTUAL,
MOTIVATIONAL, PLAYFUL_DE_ESCALATING, PROFESSIONAL, CONCISE, CLARIFYING, and
NEUTRAL_ADAPTIVE.
