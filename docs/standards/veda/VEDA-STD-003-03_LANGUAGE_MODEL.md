# Language Model

Wave 1 supports EN, HI, Romanized Hindi, Devanagari Hindi, and HINGLISH.
Language detection is deterministic and conservative. Mixed Hindi/English
messages are not forcibly translated into one language.

Language-pack data is separate from universal conversational logic and may
contain expressions, idioms, phrases, slang, register, script, regional
variants, and pragmatic markers. Wave 2 packs are planned for Bengali, Tamil,
Telugu, Marathi, Gujarati, Punjabi, Kannada, Malayalam, and Urdu.

Unknown language or low confidence uses neutral adaptive output.
