# Reasoning Layers

1. Deterministic facts: calculations and chart/runtime facts only.
2. Classical reasoning: source-backed rules, trust zones, provenance, variants, and validation state.
3. Intuitive/empirical reasoning: pattern matches, convergence, expert reasoning, historical outcomes, and ML evidence.

The third layer is structured pattern recognition, never an unsourced classical fact. Evidence carries its layer, type, source, method, family, dependency, and confidence.
