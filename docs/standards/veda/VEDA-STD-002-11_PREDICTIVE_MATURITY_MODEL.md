# Predictive Maturity

`PRED-M0` means no structured predictions. `PRED-M1` means timestamped experimental predictions. `PRED-M2` adds outcome capture. `PRED-M3` adds evaluation/backtesting. `PRED-M4` adds confidence calibration, `PRED-M5` pattern learning, `PRED-M6` validated domain performance, and `PRED-M7` production consideration. This implementation reaches the M2/M3 boundary: contracts and evaluation exist, but real resolved samples are not present.
