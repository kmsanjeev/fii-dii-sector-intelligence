# Knowledge Lifecycle

SOURCE -> DOCUMENT -> PASSAGE -> CLAIM -> CLASSIFICATION -> CROSS-REFERENCE -> CONTRADICTION CHECK -> METHOD VARIANT -> RESEARCH_CANDIDATE -> VALIDATION -> EXPERIMENTAL/SHADOW -> PROMOTION_READY -> ADMIN APPROVAL -> APPROVED_CORE -> ACTIVE.

Records retain source, document, passage, claim, rule, source class/family, trust zone, validation, method variant, confidence, conflicts, supersession, and version metadata. Missing exact references use `REFERENCE_NOT_VERIFIED`.
