# Adaptive Response

COMM-002 is the implemented response-adaptation layer for this standard. It
provides bounded presentation guidance to the existing ChatEngine; it does not
replace the response owner or alter factual, trust, predictive, empirical, or
safety state. See `docs/current-state/comm-002/`.

Expression levels range from formal/literal through natural, conversational,
idiomatic, highly informal, and slang-rich. The analyzer supplies a response
strategy and the existing ChatEngine remains responsible for final prose.

Explanation depth adapts to domain proficiency. Advanced Jyotisha or software
users need not receive basic definitions unless useful; beginner questions
receive context. Warmth never weakens safety, trust, prediction, finance, or
health boundaries.
