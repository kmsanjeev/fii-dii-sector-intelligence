# VEDA-EMP-002 — Historical Case Acquisition & Leakage-Readiness Audit

## Mission

Assess whether VEDA can begin legitimate historical or prospective empirical
case acquisition without fabricating subjects, outcomes, provenance or
prediction chronology.

## Boundaries

- Reuse EMP-001, ADM-EMP-001, PRED-001 through PRED-003 and the shared case registry.
- Do not create synthetic or retrospective cases as empirical evidence.
- Do not alter prediction outcomes, calibration, predictive maturity or human-validation status.
- Do not add a second empirical database, provider dependency or ML model.
- Record `0` eligible cases honestly if no qualifying source is available.

## Required work

1. Audit the existing case, prediction and outcome contracts.
2. Inspect the current inventory and classify excluded material.
3. Check provenance, chronology, consent/privacy and leakage gates.
4. Identify the smallest legitimate acquisition path.
5. Add only governance documentation and deterministic checks if needed.
6. Synchronize current state and roadmap without claiming empirical progress.
