# Bindu/Rekha polarity

The numerical evaluator uses `qualifying contribution = 1` and `non-qualifying contribution = 0`. The accessed Saravali transcription uses the descriptive terms in the opposite direction (`Rekha` for benefic influence and `Bindu` for malefic dots). This is recorded as a possible terminology/polarity equivalence and is not treated as a numeric contradiction until the complete witness is verified.
