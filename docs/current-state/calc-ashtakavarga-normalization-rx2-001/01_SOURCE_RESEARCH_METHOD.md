# Source research method

Existing VEDA artifacts were audited first. BPHS and Phaladeepika matrices from
the parent cross-source activity were reused rather than re-extracted. Lawful
official Journal of Astrology, Bharatiya Vidya Bhavan, Google Books, WisdomLib,
Saravali and public vendor-sample routes were checked on 2026-08-19. Full books,
pirated mirrors, search snippets and unsourced copied tables were not treated as
authority. Classical and K.N. Rao implementation-tradition evidence remain on
separate axes. Where a full passage or numerical table was unavailable, the
result is recorded as bibliographic-only, incomplete or `REFERENCE_NOT_VERIFIED`.

The public Triple-S PDF was inspected at page 2 because it is a numerical
implementation witness for the 337/386 convention; it is not used as classical
or direct K.N. Rao proof. No raw book text or personal data is committed.
