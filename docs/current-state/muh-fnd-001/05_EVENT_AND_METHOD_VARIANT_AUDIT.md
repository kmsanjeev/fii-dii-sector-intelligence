# Event and Method Variant Audit

## Event taxonomy

No production event taxonomy exists. A future implementation must distinguish,
at minimum, marriage, travel, education, construction/property, naming,
initiation, medical/procedural and business/contract events. This list is a
readiness recommendation, not an activated contract.

## Variant policy

Different schools may differ in preferred stars, tithis, karanas, exceptions,
local day definitions and personal Bala systems. These must be represented as
method variants with source lineage. Repeated modern tables are not independent
evidence.

## Explicit non-equivalences

- birth Panchanga != electional Muhurta
- a favorable limb != favorable complete event window
- pilgrimage/travel timing != spiritual maturity
- a traditional exception for marriage != universal rule
- local convention != classical primary authority
- a computed value != an interpretation or recommendation
