# VEDA-PRED-004 — Prospective Shadow Prediction Pilot

Establish a governed pilot over the existing PRED-001 through PRED-003
prediction registry. Predictions must be specific, timestamped, source-aware,
locked before outcome information, and scored only after independently observed
outcomes.

No fake subject, prediction, outcome, confidence statistic or calibration claim
may be created. A legitimate public-observation or consented subject is still
required for a live record.
