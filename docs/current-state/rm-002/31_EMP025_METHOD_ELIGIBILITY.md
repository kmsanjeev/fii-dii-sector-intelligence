# VEDA-EMP-025 Method Eligibility Register

Status: `PRE_PILOT_FROZEN`

The corpus is not yet large or diverse enough for a method-comparison pilot.
This register freezes what may be evaluated when the corpus gate is met.

| Method family | Status | Permitted role | Reason |
|---|---|---|---|
| Existing D1 natal calculation facts | `ELIGIBLE_PRIMARY` | descriptive feature generation | existing runtime foundation; no outcome claim |
| Existing Dasha / transit facts | `CONDITIONAL` | timing features only | must retain their existing trust labels |
| BAV / SAV | `RESEARCH_ONLY` | diagnostic comparison only | not validated for primary empirical inference |
| Unvalidated Varga interpretation | `DEFERRED` | none | calculation does not establish interpretation |
| Generic online yoga lists | `REJECTED` | none | no reproducible provenance |

No method may be tuned against the holdout split. No chart-derived feature may
be used to select the subjects.
