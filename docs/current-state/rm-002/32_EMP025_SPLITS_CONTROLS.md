# VEDA-EMP-025 Splits and Controls

Status: `PRE_PILOT_FROZEN`

Splits are subject-level and deterministic: stable subject IDs are ordered by
SHA-256 digest, then assigned approximately 40% DESIGN, 30% VALIDATION and the
remainder HOLDOUT. The current frozen artifact guarantees non-empty validation
and holdout partitions. The artifact is generated by
`scripts/veda_emp_025_split.py`; event multiplicity must never put the same
subject in more than one split.

Controls frozen before any method evaluation:

- matched time-window control;
- event-label shuffle control;
- subject/event permutation control;
- bounded time-perturbation sensitivity control;
- random-baseline comparison.

These are design controls, not positive evidence. The current corpus is too
small and death-only to run them as a meaningful method evaluation.
