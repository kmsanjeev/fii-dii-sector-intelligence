## Question

Which Tajika foundation dependency is currently unresolved?

## Finding

The repository has one usable annual/Tajika evidence route: Hāyanaratna,
represented by `SRC-KT-02` and the Wellcome edition metadata in `SRC-KT-05`.
That evidence is method-scoped and supports annual journey configurations. It
does not, by itself, define a complete annual-return or Varshaphala calculation
contract.

The unresolved dependency is therefore a governed method-and-calculation
foundation, not a missing interpretation table:

1. an authoritative annual-chart edition and passage register;
2. the annual return/solar-return chart construction convention, including
   ayanamsa, location, house system and boundary handling;
3. source-resolved definitions and algorithms for Muntha, annual lord,
   Tajika aspects and Sahamas; and
4. deterministic fixtures and expert review sufficient to validate the above
   before any annual interpretation or timing claim is enabled.

## Decision

`TAJIKA_FOUNDATION` remains research-ready but calculation-blocked. No runtime
code, production prediction behavior, empirical case, prospective subject,
Approved Core rule or RAG promotion is authorized by this activity.

The next Tajika activity should obtain or verify a citable annual-method
edition and build a source-to-contract matrix. Only after that matrix is
complete should a narrow deterministic annual-chart fixture be proposed.
