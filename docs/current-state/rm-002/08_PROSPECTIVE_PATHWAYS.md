# Prospective Pathways

PRED-004's contract, freeze-before-outcome, leakage audit and outcome states
are usable, but no legitimate prediction exists.

Potential governed classes include publicly scheduled corporate appointments,
public competitions, scheduled launches and other observable events where the
astrological domain is appropriate. Each requires an identified subject or
public entity, event definition, cutoff, chart provenance, method version,
observation window and ethical review. Elections, health and private life
events remain restricted unless separately authorized.

The gap is input discovery and eligibility, not prediction-engine code.
Create `PROSPECTIVE_SUBJECT_DISCOVERY` as a human-input-helpful track; do not
manufacture records.
