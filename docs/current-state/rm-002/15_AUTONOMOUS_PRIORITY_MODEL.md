# Autonomous Priority Model

The scheduler uses ordinal bands rather than fake precision. Candidate
activities are reviewed across: predictive impact, trust-chain importance,
source availability, engineering feasibility, empirical testability,
dependency readiness, duplication risk and expected information gain.

Priority order:

1. Timing validation — unlocks event-window reasoning across frozen domains.
2. Classical source expansion — improves rule authority and RAG reachability.
3. Method comparison — prevents false consensus across Varga/timing methods.
4. Tajika foundation — fills a major annual-forecasting desert.
5. Ashtakavarga/Shadbala validation — improves strength and transit evidence.

Human-input tracks run longitudinally and do not block the research queue.
