- Core D1 facts, Dasha facts, transit astronomy, D4 and D20 selected routing
  have deterministic implementations and tests.
- D20 remains `PARTIALLY_VALIDATED`: BPHS category starts are governed, while
  destination mapping is an explicit sequential inference.
- D9/D10/D12/D60 calculations exist with mixed `IMPLEMENTED_WITH_CONDITIONS`
  status; interpretation is not thereby authorized.
- Shadbala exposes source claim IDs but components return
  `IMPLEMENTED_UNVALIDATED` or `RESEARCH_REQUIRED`.
- BAV/SAV calculation paths exist in the Shadbala module but predictive use is
  not source- or empirically validated.
- No governed Tajika/Varshaphala annual-chart calculation path was identified.
