# P028 Architecture

`P028CompatibilityEngine` validates the subject pair, consumes P024/P027 evidence, preserves Chart A/B and subject A/B identity, derives multidimensional relationship states, retains A-to-B/B-to-A/MUTUAL directionality, and delegates evidence synthesis to `P027SynthesisEngine`.

The result is not a magic score. Existing ChatEngine/COMM/EMO layers may adapt presentation; P028 owns only governed relationship synthesis.
