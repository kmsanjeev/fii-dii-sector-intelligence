# Event Contract and Safety Gates

The foundation recognizes taxonomy labels only:

`MARRIAGE`, `TRAVEL`, `EDUCATION`, `CONSTRUCTION_PROPERTY`, `NAMING`,
`INITIATION`, `MEDICAL_PROCEDURE`, `BUSINESS_CONTRACT`.

Recognition is not recommendation. Every result carries:

- `activation_status = INACTIVE`
- `recommendation_status = NOT_IMPLEMENTED`
- `event_rules = NOT_IMPLEMENTED`
- `tarabala = NOT_IMPLEMENTED`
- `chandrabala = NOT_IMPLEMENTED`
- `electional_scoring = NOT_IMPLEMENTED`
- `prashna = OUT_OF_SCOPE`

Invalid coordinates, timezone identifiers and event labels fail explicitly.
