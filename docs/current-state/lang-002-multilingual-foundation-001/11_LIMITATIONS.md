# Limitations

1. Only the canonical English baseline is an implemented content locale.
2. Hindi and other voice locales are not authorized translated Jyotisha packs.
3. English presentation strings remain `REVIEW_PENDING`; no human or source
   review is claimed.
4. The registry is a bounded seed vocabulary, not a complete translation of
   every frontend label or every classical term.
5. Free-text interpretations remain canonical-text-only until reviewed
   translations exist.
6. This activity does not validate linguistic quality, cultural register, or
   human preference for a future language pack.
7. P032 recommendations remain inactive; D20 interpretation remains not
   validated; Ashtakavarga remains research-only/implemented-unvalidated.
