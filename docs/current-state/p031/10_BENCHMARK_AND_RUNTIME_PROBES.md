# P031 Benchmark and Runtime Probe Record

The benchmark is generated in the test layer rather than production code, so fixture IDs and exact benchmark phrases cannot affect synthesis. It contains 160 development scenarios and a separate 50-case holdout, with minimum category coverage for interest/maturity (20), religiosity/inner development (15), detachment/distress (15), pilgrimage/renunciation (15), D20 gating (15), timing (25), and contradiction (15).

Runtime probes cover dharma, philosophy, devotion, contemplation, interest without discipline, householder spirituality, detachment, pilgrimage, renunciatory tendency, mixed material/spiritual evidence, transformation, Ketu safety, D20 missing/calculation-only states, inactive and convergent timing, contradictions, birth-time uncertainty, and subject identity. Each must return a non-empty governed result, retain reasoning and trust labels, and avoid enlightenment, clinical, superiority or formal-renunciation certainty.

Performance is measured with provider calls added equal to zero. P031 is deterministic and operates over supplied facts only.
