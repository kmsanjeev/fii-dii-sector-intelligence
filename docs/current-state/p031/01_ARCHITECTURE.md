# P031 Architecture

`SpiritualityDharmaSynthesisEngine` consumes supplied governed `spiritual_scores`, optional house/Varga metadata, and Dasha/Transit activation state. It does not calculate astronomy, infer clinical conditions, select a guru, or claim enlightenment.

P027 remains the cross-domain evidence and contradiction owner. P031 is a deterministic life-domain adapter, analogous to P030, and returns a typed result with supporting/opposing evidence, conditions, alternatives, missing-data degradation, timing, confidence, and trust state.

Trust state is `RESEARCH_CANDIDATE`. No Approved Core promotion or RAG rebuild occurs.
