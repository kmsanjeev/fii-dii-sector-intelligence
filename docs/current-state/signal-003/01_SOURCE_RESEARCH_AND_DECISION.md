# VEDA-SIGNAL-003 — Source Research and Decision

## Source method

The audit applied the permanent sequence:

`SOURCE_GOVERNANCE → IMPLEMENTATION_REACHABILITY → OUTCOME_BLIND_PREVALENCE → EMPIRICAL_VIABILITY → CASE_ACQUISITION → PILOT → REPLICATION`.

Education was inspected first, with separate event types: education start,
higher-education entry, degree completion, and education completion. The
accessible [Brihat Parashara Hora Shastra](https://vedic-astro.s3.amazonaws.com/books/bhrihat_parasara_hora_shastra.pdf)
contains educational-sphere and educational-improvement results in its Dasha
material. Those passages support a broad educational theme, not a deterministic
publicly dateable start or completion event with a complete timing rule.

Modern web lists were treated as discovery only. No anonymous, SEO, copied or
unsourced yoga list was promoted. No Sanskrit quotation or passage reference
was invented.
