# Context Assembly

Unified context assembly now emits structured trust-separated sections:
- `APPROVED CORE KNOWLEDGE`
- `KNOWN CONFLICTS`
- `LOCAL PLATFORM EVIDENCE`
- `ML / PREDICTIVE SIGNALS`
- `REVIEWED INTERNAL MEMORY`
- `LEGACY UNSOURCED KNOWLEDGE`

Rendered approved-core entries include:
- version state
- authority summary
- citation labels
- reliability note

This keeps evidence classes explicit all the way into the model prompt.
