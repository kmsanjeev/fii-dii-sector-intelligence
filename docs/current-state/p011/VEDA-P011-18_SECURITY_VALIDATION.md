# Security Validation

P011 preserves existing research and retrieval trust boundaries.

Important retained protections:
- approved-core retrieval does not promote anything
- temporary external research remains data, not instructions
- citation labels come from governed metadata, not from arbitrary source strings
- Admin diagnostics are served from admin-only research routes
- superseded and withdrawn core versions are excluded from active retrieval

Prompt injection and source-as-data protections remain inherited from P006 through P009-R1.
