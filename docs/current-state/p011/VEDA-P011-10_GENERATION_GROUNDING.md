# Generation Grounding

P011 does not introduce a post-generation astrology claim parser.

It does strengthen grounding through:
- trust-separated context
- explicit citation metadata
- prompt rules forbidding fabricated source details
- prompt rules requiring inference labelling when support is exceeded
- prompt rules preserving approved-core versus temporary-research differences

Runtime grounding is therefore prompt-governed plus retrieval-traceable, with diagnostics and tests around the contract.
