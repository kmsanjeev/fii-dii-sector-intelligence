# Materiality Model

Materiality is deliberately non-predictive in this phase. Each normalized
event carries:

```json
{"state": "UNKNOWN_MATERIALITY", "predictive": false}
```

No price impact, recommendation, target, BUY/SELL label, or outcome score is
created. Classification confidence is not materiality and is not predictive
confidence. A future materiality policy would require a separate governed
activity and explicit source/issuer methodology.
