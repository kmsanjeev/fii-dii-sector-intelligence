# Retention, Withdrawal and Deletion

Retention periods are provisional and not legal conclusions. The review must
set active retention by data class, post-withdrawal treatment, backup handling,
deletion method and approving authority.

The synthetic test exercises optional-scope withdrawal, stop-contact state,
future-research stop, identity-linkage severance, withdrawn status, backup
tombstone requirement and an audit event. Real deletion, anonymization and
backup erasure are not implemented because no real stores exist.
