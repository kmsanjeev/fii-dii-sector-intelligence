# Security Readiness

Status: `EXTERNAL_SECURITY_REVIEW_REQUIRED`.

Required before recruitment: strong authentication and least privilege; role
separation; encryption in transit and at rest; managed secrets; immutable audit
events; isolated, authenticated, authorized and scanned document uploads;
encrypted backups; export approval; deletion verification; environment
isolation; dependency/security scanning; incident response; and a review of
IDOR, reidentification and admin-compromise controls.

The current activity implements no production endpoint or security boundary.
The controls are requirements and test targets, not evidence that deployment is
secure.
