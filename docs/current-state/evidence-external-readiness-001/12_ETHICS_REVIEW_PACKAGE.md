# Ethics Review Package

Independent review materials cover the question, scientific purpose, current
insufficient empirical maturity, adult population, inclusion/exclusion,
voluntary recruitment, consent, burden, documentary sensitivity, longitudinal
follow-up, withdrawal, privacy, retention, complaints, dissemination, conflicts
and the prohibition of medical, death and financial certainty claims.

ICMR applicability is not self-determined. The protocol must be classified by
an independent ethics reviewer. No IRB/IEC approval has been obtained or
claimed. Recruitment remains blocked.
