# Consent Form — Draft, Not for Distribution

Consent version: `DRAFT-EXTERNAL-READINESS-1.0`.

The form must record separate yes/no choices for: core research, birth-document
verification, longitudinal follow-up, event-document submission, aggregated
publication, deidentified research sharing and future recontact. Each choice
records version, timestamp, actor and notice text. Refusing an optional scope
must not block the core choice unless the approved protocol says the data is
essential.

Scope changes apply prospectively only. Withdrawal stops new contact and future
research use according to the approved policy; already-created lawful snapshots,
audit records and aggregate outputs require counsel-approved treatment. No
retroactive expansion is permitted.
