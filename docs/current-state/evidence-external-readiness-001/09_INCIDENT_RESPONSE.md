# Incident Response Plan

1. Detect and preserve relevant logs without spreading the data.
2. Contain: disable affected credentials, uploads, exports or endpoints.
3. Revoke access and rotate secrets; preserve a controlled forensic record.
4. Escalate to the Founder, legal/privacy counsel and ethics reviewer.
5. Decide notification and regulator/participant communications with counsel;
   no jurisdictional deadline is asserted here.
6. Recover from verified clean state and confirm deletion/tombstone handling.
7. Record root cause, participant impact, protocol deviation and corrective
   action before any restart decision.

Any confirmed privacy/security incident suspends recruitment and external
sharing until independently reviewed.
