# Recruitment Protocol — Draft, Not Executed

Adults only by default; India is the initial jurisdiction. Recruitment channels
must be approved, non-coercive and transparent. No public registration exists.
Compensation, support contact, complaints route, screening script and language
accessibility require Founder/legal/ethics approval.

Screening must prevent duplicates, explain documentary evidence expectations,
record burden and allow refusal. No participant is promised a reading, benefit,
prediction or research result. Recruitment stops for a privacy/security
incident, participant harm, consent defect, legal-review change, document
processing failure, unauthorized access, excess burden or protocol deviation.
