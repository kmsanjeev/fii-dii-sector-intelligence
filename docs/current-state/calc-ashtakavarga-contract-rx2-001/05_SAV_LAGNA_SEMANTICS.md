# SAV and Lagna semantics

`RAW_PLANETARY_SAV` is the sum of the seven planetary BAV target vectors and has grand total 336. Lagna is not included in that ordinary SAV. `RAW_LAGNA_BAV` is a separate target/vector with grand total 49. An optional `RAW_SAV_WITH_LAGNA_COMBINED` view is arithmetic 336 + 49 = 385 and must not be labelled simply `SAV`.
