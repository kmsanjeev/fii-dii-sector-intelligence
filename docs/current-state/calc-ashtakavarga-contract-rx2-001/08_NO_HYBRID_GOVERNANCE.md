# No-hybrid governance

Reusable rule: `NO_CROSS_TRADITION_INVARIANT_MERGE_WITHOUT_EQUIVALENCE_PROOF`. A source matrix may not be combined with another tradition's aggregate invariant without demonstrated compatibility. V1 is preserved as the concrete invalid-hybrid lesson. Phaladeepika and Varahamihira remain explicit variants and are not merged into the BPHS-primary V2 contract.
