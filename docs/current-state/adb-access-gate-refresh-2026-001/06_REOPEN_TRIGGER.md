# Future reopen trigger

The ADB formal-access gate may be reconsidered only when the official
Astro-Databank/Astrodienst export page again offers a formal license,
contract, qualified-researcher route, or full-export route with current terms.

At reopening, the preserved package must be refreshed against the then-current
license, submission procedure, permitted fields, attribution, retention,
publication, redistribution and technical-access conditions. Human review and
explicit provider terms are required before any request, purchase, login,
download, export, programmatic access or new empirical acquisition.

No assumed calendar date is a reopening trigger. In particular, 1 January 2027
does not prove that access has reopened.

Provider-policy monitoring is useful, but this activity creates no polling
subsystem, scheduled task or automated contact.
