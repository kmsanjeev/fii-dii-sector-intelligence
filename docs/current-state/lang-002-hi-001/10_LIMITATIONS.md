# Limitations

- Hindi text is a complete 49-key machine-draft presentation pack, not human-
  reviewed or production-authorized translation.
- Free-text Jyotisha interpretations remain canonical English text until a
  reviewed translation path exists.
- Hindi alias lookup requires the `hi` presentation locale and does not alter
  calculation or query parsing.
- Devanagari technical vocabulary is bounded to the existing 33-term registry;
  no new astrology meaning was added.
- Other content locales were not created. Existing Hindi voice support is a
  separate TTS capability.
- No claims are made about linguistic perfection, source-reviewed translations,
  or cultural/regional variants.
- P032 recommendations remain inactive, D20 interpretation remains not
  validated, Ashtakavarga remains implemented but unvalidated, and prediction,
  ML, PRED-M4 and RAG are unchanged.
