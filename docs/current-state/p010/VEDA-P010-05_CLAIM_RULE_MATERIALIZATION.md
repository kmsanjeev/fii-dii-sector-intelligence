# VEDA-P010 Claim and Rule Materialization

P010 materializes approved astrology candidates into governed claims and rules while preserving the claim/passage/source chain.

Claim materialization preserves:
- domain and subdomain;
- support level;
- source and passage references;
- contradiction references;
- evidence-class distinctions.

Rule materialization preserves:
- rule identity and status;
- ontology linkage;
- provenance back to claim, passage, and source;
- future-activation separation.

Important boundary:
- promoted rules are stored as governed rule artifacts;
- they are **not** marked `IMPLEMENTED`;
- they do **not** activate production astrology execution.

Legacy mapping updates are applied only as governance metadata. Existing production logic remains untouched.
