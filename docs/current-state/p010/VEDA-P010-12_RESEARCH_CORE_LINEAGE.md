# VEDA-P010 Research-to-Core Lineage

P010 preserves both directions of lineage:

Core to research:
- core record
- promotion
- approval
- candidate
- validation
- evidence
- observation
- run
- mission

Research to core:
- candidate detail now exposes preflights, promotions, rollbacks, index-sync history, and core history;
- approved-core retrieval docs retain `core_id`, `promotion_id`, `claim_ids`, `passage_ids`, `source_ids`, and `rule_ids`.

This lineage is sufficient for future citation-aware retrieval and explanation work in P011.
