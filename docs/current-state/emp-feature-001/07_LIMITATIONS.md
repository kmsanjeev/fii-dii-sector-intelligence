# VEDA-EMP-FEATURE-001 - Limitations

- `POSITION_START` is the narrowest available public transition family, but
  its six events cover three subjects and source date precision is not uniform.
- The matched control is the same subject at a date exactly 365 days before
  the recorded event date. Event-shuffled and subject-event permutation
  controls were not run because the subject count is too small for a meaningful
  null comparison.
- The outcome-free population establishes testability, not predictive validity.
- All five features are platform-synthesis hypotheses. Results do not alter
  classical source status.
- No new untouched holdout was selected or acquired. Existing cases are marked
  `PREVIOUSLY_EXPOSED` for this study.
- All results are `INSUFFICIENT_SAMPLE`; no promising feature was declared.
- No empirical result upgrades PRED-M4, production behavior, Approved Core,
  or RAG.
