# Translation and OCR Audit

`candra-tārā-bala` context, but it does not provide a reproducible algorithm in
that verse. The available Muhurta Chintamani Chapter 5 PDF was inspected as an
actual PDF; OCR contains severe character substitutions and page fragmentation.
No formula was reconstructed from OCR alone.

Therefore:

- contextual claim: validated narrowly;
- individual algorithms: unverified;
- modern table: discovery only;
- implementation: disabled.
