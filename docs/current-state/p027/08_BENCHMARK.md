# P027 Benchmark

The deterministic focused benchmark contains 100 synthesis scenarios and covers simple, convergent, contradictory, timing, lineage, missing-data, production-safe, and chart-attribution cases. It also includes a 30-case holdout fixture in the acceptance plan; holdout execution is kept separate from development tuning.

Focused P027 tests validate evidence roles, promise/timing separation, lineage redundancy, contradiction handling, missing-data degradation, experimental filtering, two-chart identity, and the 100-scenario property run. Exact generated prose is not scored.
