# Timing Hierarchy

Structural/D1/Varga evidence represents promise or potential. Dasha and sub-Dasha activate or refine it; transit is generally a trigger or timing modifier. Timing rows are separate from promise rows.

The output retains structural promise, Dasha, sub-Dasha, transit, Varga confirmation, primary/alternative windows, timing conflict, and timing confidence. A timing signal without structural support cannot create a production-safe event promise.
