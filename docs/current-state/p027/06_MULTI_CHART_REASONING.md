# Multi-Chart Reasoning

Same-native D1/Varga/timing evidence is supported through retained chart and subject IDs. The limited two-chart contract retains `chart_a`, `chart_b`, `subject_a`, `subject_b`, relationship type, and comparison domain.

P027 does not implement compatibility, synastry, prashna, or muhurta. It returns `FOUNDATIONAL_COMPARISON_ONLY` rather than inventing those methods. Chart conflation is a critical failure and is covered by focused tests.
