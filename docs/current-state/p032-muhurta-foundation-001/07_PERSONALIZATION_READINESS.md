# Personalization Readiness

| Input/system | Status | P032 decision |
| --- | --- | --- |
| DOB/TOB/POB identity path | Existing and reusable | Inventory only |
| Natal Moon / Janma Nakshatra | Existing in Kundli path | Available as a dependency, not a recommendation |
| Tara Bala | `RESEARCH_CANDIDATE`, `REFERENCE_NOT_VERIFIED` | No executable formula |
| Chandra Bala | `RESEARCH_CANDIDATE`, `REFERENCE_NOT_VERIFIED` | No executable formula |
| Personal Lagna electional use | Not source-validated for this activity | Deferred |
| Dasha/Varga confirmation | Existing systems, not a Muhurta selection rule | Not used |

P032 therefore remains D1/Panchanga fact-first and does not emit a
person-specific “good time.” Birth-time quality and missing location/timezone
metadata remain explicit blockers for any future personalization layer.
