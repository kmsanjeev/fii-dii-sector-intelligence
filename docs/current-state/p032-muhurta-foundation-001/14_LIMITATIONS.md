# Limitations

- No public Muhurta recommendation API or UI was added.
- No best-time, auspiciousness, ranking, or composite score is emitted.
- Tara Bala and Chandra Bala remain `RESEARCH_CANDIDATE` because the existing
  source witnesses do not provide a verified operative passage/formula.
- The Bṛhat Saṃhitā claims are scoped event action families, not universal
  good/bad labels.
- Solar-day times retain the existing NOAA low-precision approximation and are
  not a replacement for a higher-precision ephemeris.
- Historical timezone/DST changes and polar sunrise/sunset absence remain
  explicit input/coverage limitations.
- This work validates calculation contracts and does not validate predictive
  outcomes, ML, PRED-M4, or empirical claims.
- Prashna, D20, and prior Muhurta research boundaries are unchanged.
- No Approved Core promotion occurred.
