# VEDA-P002-06 Versioning Standard

## IDs Now Enforced

- sources: `VEDA-SRC-*`
- passages: `VEDA-PSG-*`
- claims: `VEDA-CLM-*`
- conflicts: `VEDA-CNF-*`
- approvals: `VEDA-APR-*`
- policies: `VEDA-PLC-*`
- legacy registers: `VEDA-LGC-*`
- legacy rules: `VEDA-LRY-*`

## Version Rules

- semantic version required
- ISO timestamp required
- no silent overwrite
- explicit change reason required
- explicit supersession fields required

## Why This Matters

Astrology research can now evolve as governed artifacts instead of as unversioned prose or hardcoded assumptions.
