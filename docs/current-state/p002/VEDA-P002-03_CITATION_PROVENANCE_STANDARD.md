# VEDA-P002-03 Citation Provenance Standard

## Evidence Chain

P002 establishes the required separation:

`source -> passage -> claim -> future rule`

## Key Rule

VEDA can no longer treat:

- a source record,
- a translated passage,
- a research interpretation,
- and a future machine rule

as if they were the same thing.

## Pilot Evidence Notes

- archive-based passages are paraphrased into governed records
- Brihat Jataka 8.20 includes Sanskrit and transliteration because the online edition presents both
- translator notes are preserved as commentarial evidence instead of being mislabeled as root classical verses
