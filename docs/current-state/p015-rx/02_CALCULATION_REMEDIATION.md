# Calculation Remediation

Only D4 routing changed. The shared `general` method remains available to unrelated Vargas. The source-selected branch uses numeric longitude, normalized sign index and floor-based interval selection; it has no odd/even parity dependency.

Output metadata distinguishes `calculation_status=VALIDATED` from `interpretation_status=NOT_VALIDATED`, with method ID/version and source reference. No D4 property rules were added.
