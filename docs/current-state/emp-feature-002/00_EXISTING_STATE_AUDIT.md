# VEDA-EMP-FEATURE-002 - Existing State Audit

EMP-FEATURE-001 froze five atomic Mahadasha/D1 feature contracts and found
usable outcome-free prevalence, but only six `POSITION_START` events across
three previously exposed subjects. This programme reuses those exact five
contracts and the verified POP-001 baseline.

The birth-first source pool contains 1,000 chart-ready timed identities. A
new cohort of 20 non-overlapping identities was selected before feature
calculation. All selected records have source-provided timed births, resolved
coordinates, chart-ready D1/Vimshottari calculations, and a documented public
or professional start event. The cohort source file records event precision,
source type, URL, and retrieval date.

No subject was selected using a feature, Dasha state, transit state, or
expected result. No existing holdout was opened. The five feature hashes were
verified before scoring.
