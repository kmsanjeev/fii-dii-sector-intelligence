# Market exposure

Market, sector, stock, F&O, corporate, research, portfolio, risk, execution,
broker and backtest implementations have API and/or dedicated UI surfaces.
Representative market/sector/stock/corporate prompts reach their intended
capabilities and specialist prompts retain their established context.

The AstroFinance route remains separate and `get_astro_signal` is not exposed
to GENERAL or ordinary ASTRO. However, the generic tool list retained by
MARKET/SECTOR/STOCK/CORPORATE turns contains all 23 registered tools, including
unrelated Jyotish tools. This is a P1 tool-scope remediation candidate, not a
market data outage.
