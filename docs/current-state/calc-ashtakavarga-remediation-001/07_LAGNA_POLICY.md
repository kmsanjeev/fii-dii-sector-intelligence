# Lagna Policy

The frozen contract says that Lagna is a separate optional target/contributor
where the source table explicitly supplies it. Ordinary planetary SAV excludes
Lagna; the combined display is separate and must not be called ordinary SAV.

The source matrix gives Lagna a total of 49. Because the same matrix gives the
planetary sum 336, the combined total is 385, not the contract's 386. Lagna
policy therefore remains documented but not activated.
