# Swing model

Swing setup states are derived from short and medium EOD trend/momentum,
volatility, freshness, event risk, sector/market alignment and conflicts.
Possible states include `BULLISH_SETUP`, `BEARISH_SETUP`,
`WATCHLIST_SETUP`, `CONFLICTING_EVIDENCE`, `EXTENDED`, `RANGE_BOUND`,
`RISK_BLOCKED` and `INSUFFICIENT_EVIDENCE`. No entry order or target is
generated.
