# VEDA-MARKET-POSITIONAL-AND-SWING-INTELLIGENCE-001

Status: IMPLEMENTED / OPERATIONAL_WITH_CONDITIONS
Date: 2026-08-21

This activity establishes a deterministic, read-only EOD setup-intelligence
layer for two explicit horizons: SWING (approximately 2–20 trading sessions)
and POSITIONAL (approximately 10–60+ sessions). It composes existing governed
technical, momentum, F&O, market, sector, Theme, institutional, fundamental
and corporate evidence. It does not create a trading engine, recommendation
engine, target model, order path, intraday path, ML path or predictive claim.

The FII-DII repository remains the Market data/calculation owner. VEDA is a
read-only provider/routing boundary. The final decision is
`VEDA_MARKET_POSITIONAL_AND_SWING_INTELLIGENCE_OPERATIONAL_WITH_CONDITIONS`.
