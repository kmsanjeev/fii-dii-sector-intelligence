# Horizon model

| Horizon | Formal scope | Distinction |
|---|---|---|
| SWING | approximately 2–20 trading sessions | shorter EOD continuation/reversal context |
| POSITIONAL | approximately 10–60+ sessions | broader trend, event and structural context |

The same evidence may support both horizons but is interpreted through the
requested horizon. A positional result is not a promise of a longer-term
outcome, and a swing result is not intraday guidance.
