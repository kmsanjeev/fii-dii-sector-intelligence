# Privacy and data minimization

No natal data, birth records, database migration, profile storage, logging path,
RAG document, or public API was added.

Future implementation should calculate personal factors in memory, accept a
reliable user-supplied Janma Nakshatra/Moon sign when appropriate, avoid raw DOB/
TOB/POB logging, expose whether facts were user-supplied or VEDA-derived, and
surface boundary uncertainty instead of silently retaining or guessing data.
