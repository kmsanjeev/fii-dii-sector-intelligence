# Personalized window-search readiness

The frozen window-search architecture can support a future overlay without
recomputing general facts: each general candidate window already has a
representative event instant and source trace. A future personal layer could
consume the event Nakshatra/Moon-sign facts once and attach Tara/Chandra results
to each candidate.

Readiness is architectural only. No overlay, personalized ranking, API field,
or production behavior is activated here. General window search remains
unchanged and usable without birth data.
