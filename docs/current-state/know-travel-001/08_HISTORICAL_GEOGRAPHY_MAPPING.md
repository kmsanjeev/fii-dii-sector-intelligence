# Historical Geography and Sanskrit Term Mapping

| Term | Literal/contextual meaning | Modern inference allowed? | Limitation |
|---|---|---|---|
| pravāsa / pravasa (प्रवास) | Being away, journey, temporary or foreign residence, absence from home | Away-from-home or sojourn; cautiously “foreign” only where context says so | Does not specify a modern nation, visa status, permanence or immigration |
| vipravāsa (विप्रवास) | Staying abroad / dwelling away from home in lexical sources | Foreign/distant residence in the source context | Lexical evidence is not a horoscope rule |
| yātrā / yatra (यात्रा) | Journey, travel, pilgrimage/procession depending on context | Journey or pilgrimage if context supports it | Duration and destination are not implied |
| deśāntara / desantara | Another country/region/land in lexical usage | Another region or jurisdiction in source context | Ancient “country” may mean kingdom/region, not a modern nation-state |
| videśa / videsha | Foreign/other land in later and lexical usage | Foreign or outside the familiar homeland context | Modern passport-era mapping is uncertain |
| dūra-deśa / distant land | Distant region/land | Distant movement context | Distance is not automatically cross-border or permanent |

Governance categories: `AWAY_FROM_BIRTHPLACE`, `DISTANT_REGION`, and `FOREIGN_JURISDICTION_MODERN_MAPPING_UNCERTAIN`. The last category must not be collapsed into “immigration”. Translation uncertainty is material whenever “foreign”, “country”, “home” or “journey” changes the claim.
