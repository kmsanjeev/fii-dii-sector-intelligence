# Rule Classification Standard

Rules are categorical: HARD_EXCLUSION, STRONG_NEGATIVE, PREFERENCE_NEGATIVE, NEUTRAL, PREFERENCE_POSITIVE, STRONG_POSITIVE, HARD_REQUIREMENT, PERSONAL_FACTOR, CONTEXT_DEPENDENT, SOURCE_VARIANT, or UNRESOLVED. Current classical event families remain context-dependent. No universal hard exclusion or score is promoted. Platform safety gates are separate and non-bypassable.
