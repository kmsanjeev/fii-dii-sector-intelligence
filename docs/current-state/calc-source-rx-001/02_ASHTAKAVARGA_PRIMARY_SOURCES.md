# Ashtakavarga Primary Sources

The accepted primary source is BPHS Chapter 66, with reduction chapters 67–69. The inspected translation is recorded in `01_SOURCE_SEARCH_REGISTER.json` and the complete source table is recorded in `04_ASHTAKAVARGA_SOURCE_RULE_MATRIX.json`.

Source: [https://vedic-astro.s3.amazonaws.com/books/bhrihat_parasara_hora_shastra.pdf](https://vedic-astro.s3.amazonaws.com/books/bhrihat_parasara_hora_shastra.pdf)

The passage supports eight reference points (seven planets plus Lagna), contributor-specific Rekhaprad lists, and subsequent Trikona, Ekadhipatya and Pinda Shodhana chapters. Translation uncertainty remains explicit; no production rule was changed.
