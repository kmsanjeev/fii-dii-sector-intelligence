# Muhurta access remediation

Explicit Muhurta, Griha Pravesha/house-entry, and bounded auspicious-window
phrases route to `MUHURTA`. Generic Nakshatra questions route to `ASTRO`.
`MUHURTA` has an independent configurable state and does not inherit the
ASTRO or GENERAL toggle.

The route remains subject to existing Muhurta capability and source gates.
RX1 adds no new Panchanga semantics, activity rules, scoring, ranking or
recommendation behavior.
