# General chat configuration

`GENERAL_CHAT` defaults to enabled and may be disabled through the existing
central access policy. When disabled, ordinary conversation receives the
existing configuration denial. `CORE_INTERACTION` remains enabled and
protected for system, safety, configuration and error interaction. Market and
other specialist capabilities remain independently configurable.

Configuration reset was exercised by the focused API tests. No maturity or
runtime state is writable through this policy.
