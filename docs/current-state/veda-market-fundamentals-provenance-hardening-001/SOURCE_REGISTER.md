# Source register

| Source family | Dataset | Use | Decision |
|---|---|---|---|
| NSE XBRL | quarterly and extended results | Direct facts and bounded aggregates | Accepted with period/filing limitations |
| Provider-local derived output | extended financials | Explicit derived observations | Accepted as derived, not direct filing evidence |
| Legacy provider output | valuation scores | Ratio context only | Retained with `LEGACY_PROVIDER_OUTPUT` authority |
| Reference import | reference fundamentals master | Discovery/classification | Not promoted to core financial evidence |

No anonymous web source, copied SEO table, external oracle, raw provider export,
or parallel data authority was added.
