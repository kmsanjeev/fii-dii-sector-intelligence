# VEDA-MARKET-FUNDAMENTALS-PROVENANCE-HARDENING-001

Status: `OPERATIONAL_WITH_CONDITIONS`

This activity adds the provider-local `fundamental-evidence-1.0` evidence
projection to the existing stock-intelligence and cross-layer contracts. It
does not replace legacy fields, recalculate market data, or create a second
identity layer. Raw provider data and generated intelligence remain local.

The projection separates source, direct/derived status, reporting period,
period end, filing date, local retrieval time, frequency-aware freshness,
missing-value reason, financial-sector applicability, and legacy valuation
limitations. It is descriptive evidence, not a valuation recommendation,
prediction, ML feature, or PRED output.

The predecessor direct institutional gates remain unchanged:
`NO_GOVERNED_DIRECT_DAILY_STOCK_FLOW_SOURCE` and
`NO_GOVERNED_DIRECT_SECTOR_FLOW_SOURCE`.
