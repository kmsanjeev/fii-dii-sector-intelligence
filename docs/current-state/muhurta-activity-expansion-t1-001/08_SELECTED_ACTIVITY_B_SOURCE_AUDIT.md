# Selected activity B — consecration/installation commencement

Source activity class: `ABHISHEKA_SHANTI_DHRUVA_ESTABLISHMENT_ACTION_FAMILY`.

The consulted Bṛhat Saṃhitā chapter 97.06 passage places consecration,
pacification, planting/establishment and related fixed beginnings within the
fixed/dhruva Nakshatra action family. VEDA narrows this to an explicit
consecration or deity/temple installation subtype.

The contract does not generalize across puja, homa, japa, vrata, initiation,
or every religious tradition. Ritual lineage and practitioner guidance remain
mandatory context. No personal Bala or spiritual outcome claim is used.
