# Activity selection decision

Selected candidates:

1. `VEHICLE_CONVEYANCE_COMMENCEMENT` — the Bṛhat Saṃhitā light/laghu action
   family explicitly includes `yāna`/conveyance activity. The existing
   Nakshatra fact is sufficient for a narrow categorical predicate.
2. `CONSECRATION_INSTALLATION_COMMENCEMENT` — the fixed/dhruva action family
   explicitly covers consecration/establishment. A ceremony subtype remains
   mandatory, so this is not a generic religious contract.

The tie-break was source-scope clarity, then available P032 Nakshatra facts,
then practical utility. No weighted or numeric readiness score was used.

House construction/entry and marriage have strong source references but require
additional Lagna/planetary election dependencies. Travel and ritual families
remain more scope- or lineage-ambiguous. These were not selected in T1.
