# Selected activity A — vehicle/conveyance commencement

Source activity class: `SHILPA_AUSHADHA_YANA_ACTION_FAMILY`.

The consulted Bṛhat Saṃhitā chapter 97.09 passage places vehicles/conveyances
(`yāna`) within the light/laghu Nakshatra action family. The contract therefore
supports only a categorical Nakshatra compatibility indication for commencing
vehicle/conveyance use or acquisition.

It does not establish purchase affordability, safety, financing, legal title,
or successful ownership. Vara/Yoga and a vehicle-specific Tithi/Karana rule
remain nonblocking source gaps. Personal Bala remains diagnostic/source-partial.

Source lineage: `WORK → EDITION → WITNESS → PASSAGE → ASSERTION → RULE →
CONTRACT`, using `VEDA-KNOWLEDGE-SOURCE-WITNESS-STANDARD-001`.
