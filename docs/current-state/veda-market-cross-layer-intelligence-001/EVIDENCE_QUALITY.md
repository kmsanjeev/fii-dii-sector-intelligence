# Evidence quality

Quality is derived from upstream availability, freshness, date alignment,
sector breadth coverage, stock completeness, institutional coverage and
fundamental/corporate availability. It is reported as `HIGH`, `MEDIUM`,
`LIMITED` or `UNAVAILABLE` and is explicitly typed as evidence quality, not
predictive confidence.

The current live overview returned `LIMITED` quality and `DELAYED` overall
freshness because institutional data lagged the current EOD sector/stock data.
