# Sector and Theme Boundary

Sector remains a provider-owned allocation/classification layer. Theme is a
many-to-many narrative/structural layer. Theme performance is not Sector
performance, and Theme leadership is not Sector leadership. The service does
not copy Sector ranks into Theme ranks.

Stock leadership reuses existing stock intelligence and does not create a new
stock score. Theme-relative strength, market-relative strength and
sector-relative strength remain distinct fields/concepts.
