# Institutional Scope

The formal Theme contract returns `MARKET_LEVEL_CONTEXT_ONLY` and
`NO_THEME_INSTITUTIONAL_ATTRIBUTION`. Broad FII/DII data may be shown as
context through existing contracts, but no theme-specific flow is claimed
without a source that directly supports it.

This preserves `institutional-flow-1.1`, existing participant ownership and the
Corporate freeze. The Theme service does not recalculate or redistribute
participant data.
