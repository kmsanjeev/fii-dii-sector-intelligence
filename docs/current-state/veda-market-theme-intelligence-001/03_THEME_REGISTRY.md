# Theme Registry

The registry is data-driven and source-controlled. Primary classification
themes are `CAPEX_CYCLE`, `CHINA_PLUS_ONE`, `DEFENCE_ELECTRONICS`,
`DIGITAL_INDIA`, `EV_TRANSITION`, `EXPORT_GROWTH`, `FINANCIALISATION`,
`GREEN_ENERGY`, `HEALTHCARE_EXPANSION`, `INFRASTRUCTURE_BUILD`,
`LOGISTICS_MODERNISATION`, `PREMIUMISATION`, `PSU_REVIVAL`,
`REAL_ESTATE_RECOVERY` and `RURAL_CONSUMPTION`.

IDs are stable `theme.<slug>` values. Aliases are bounded discovery metadata;
they do not create memberships. New themes require the existing governance
and source-review path.
