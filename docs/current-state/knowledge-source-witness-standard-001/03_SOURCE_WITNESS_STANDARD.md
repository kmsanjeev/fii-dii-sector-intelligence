# VEDA Source Witness & Passage Governance Standard

The standard distinguishes WORK, WITNESS, EDITION, PASSAGE, SOURCE_LAYER, ASSERTION, VARIANT, AUTHORITY_PROFILE, RIGHTS and VALIDATION_STATE. IDs are deterministic, source text is never silently rewritten, variants coexist without averaging, and source authenticity remains separate from empirical validity. New source-derived contracts should identify each link or record an explicit exception.
