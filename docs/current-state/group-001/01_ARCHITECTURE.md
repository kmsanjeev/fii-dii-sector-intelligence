# GROUP-001 Architecture

`TRANSPORT METADATA + TURN TEXT -> GROUP-001 ANALYSIS -> COMM-001/LANG-001 EVIDENCE -> COMM-002 RESPONSE ADAPTATION -> EXISTING CHATENGINE`

`engines/ai/chatbot/group_conversation.py` is deterministic and in-session. It exposes `GroupParticipant`, `GroupTurn`, `GroupAnalysis`, `analyze_group_turn`, and `analyze_group_transcript`. It does not write a separate store. Internal IDs and diagnostic state are returned through existing response diagnostics only; normal prose is still generated by ChatEngine.
