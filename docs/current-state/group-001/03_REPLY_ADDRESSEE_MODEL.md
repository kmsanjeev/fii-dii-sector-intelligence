# Reply and Addressee Model

Reply-to precedence is explicit transport metadata first, then available mention/name cues, otherwise unknown. Addressing distinguishes the speaker from the recipient. VEDA states are `DIRECTLY_ADDRESSED`, `GROUP_ADDRESSED`, `NOT_ADDRESSED`, and `AMBIGUOUS`; participation is `RESPOND`, `OPTIONAL_RESPONSE`, `OBSERVE`, or `DO_NOT_RESPOND`.

A participant-directed turn does not cause VEDA to interrupt. Explicit VEDA address produces a response decision while preserving the target scope.
