# Architecture

`TravelRelocationSynthesisEngine` consumes existing numeric/domain facts under `movement_scores`, plus optional P021/P023/P024/P029 context. It does not calculate astronomy, Vargas, Dashas or Transits. P027 remains the evidence/synthesis owner.

The result separates travel, relocation, foreign residence, settlement, return, timing, contradictions, confidence and safety state.
