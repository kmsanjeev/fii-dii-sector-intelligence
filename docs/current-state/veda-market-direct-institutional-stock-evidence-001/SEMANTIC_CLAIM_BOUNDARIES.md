# Semantic claim boundaries

Allowed:

- “A disclosed bulk/block deal was observed for this symbol on the source date.”
- “Quarter-end reported FII/DII ownership changed between the two available
  reporting periods.”
- “The local participant label is a conditional client-name heuristic.”
- “Market-level FII/DII context is available but is not attributed to this
  stock.”

Not allowed:

- “FIIs bought this stock today” when only a heuristic deal label exists;
- “FIIs accumulated this sector” from market or stock evidence;
- “No deal means no institutional activity”;
- a universal institutional/smart-money score;
- converting a quarterly ownership snapshot into a daily transaction claim.
