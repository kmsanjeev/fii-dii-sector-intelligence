# Kuta Component Rules

Implemented deterministic components: Varna, Vashya, Tara cyclic distance, Yoni, Graha Maitri from Moon-sign lords, Gana, Bhakoot/Rashi distance, and Nadi. Inputs are labels expected from trusted chart calculations; unrecognized labels return `INSUFFICIENT_DATA`, not zero.

The method uses 27 Nakshatras and excludes Abhijit. The implementation uses role-neutral inputs and does not infer gender or bride/groom roles.
