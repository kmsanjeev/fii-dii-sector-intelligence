# Source Research Method

Research prioritized an inspected technical reference and a practitioner/reference PDF, then checked a primary-text scan without attributing Ashtakoota to it absent a located passage.

Sources were opened as full pages/PDF content, not search snippets. Long copyrighted passages were not copied; rules are paraphrased. Repeated modern web tables were treated as one weak lineage, not independent confirmation.

Accepted for comparison:

- Saravali, “Asta Koota,” https://saravali.github.io/astrology/astakoota.html. It identifies Moon-based Asta Koota, lists eight components and maxima totaling 36, and explicitly says it should not be the sole matching method. It is a technical secondary reference, not passage-level classical proof.
- Future Samachar / Dr Arun Bansal, *Horoscope Matching*, https://www.futuresamachar.com/download/horoscope-matching-325.pdf. Inspected pages 10, 19-25, 41, 45, 59, 78, 89 and 102 for the 36-point structure, regional variation, role-direction, Tara, Yoni, Graha Maitri, Nadi safety context and broader-chart limitation. It is a practitioner/reference work; exact classical attribution remains unverified.

Inspected but not accepted as evidence for Ashtakoota attribution: a Sanskrit Brihat Samhita scan at https://sanskritdocuments.org/doc_z_misc_sociology_astrology/bRRihatsaMhitA.pdf because no relevant Ashtakoota passage was located in this audit.

Rejected as authority: anonymous SEO/aggregation pages, copied tables without lineage, snippets, and sources that did not identify a school, edition, or rule provenance.
