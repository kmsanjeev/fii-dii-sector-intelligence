# Power Targets

The inherited research-only power planner is used for +5, +10, +15 and +20
percentage-point effects around plausible baseline prevalences. Required N is
not fixed at 200: it must be recomputed after event family, MESI, alpha,
power, controls, clustering, multiplicity and expected exclusions are frozen.

The current feasibility sample is not a validation cohort and no powered
target is authorized from it.
