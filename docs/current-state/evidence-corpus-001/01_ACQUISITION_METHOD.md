# Acquisition Method

This activity is a bounded feasibility sample: normalize existing identity and
event records, estimate source/date yields, preserve source clusters, and stop
before any chart or feature evaluation. The required sequence is feasibility
sample → yield estimate → power target → full acquisition.

Wikidata may route identity/event discovery, but it is not exact birth-time
authority. P4782 remains blocked from Astro-Databank mapping. Astro-Databank
webpage scraping is not performed.
