# Cross-layer model

Stock state is derived from the existing trend signal and complete 5D/20D price windows. Sector state is consumed from `sector-rotation-1.1` leadership/rotation fields. The bounded cross-layer states are strong/weak stock with strong/weak sector, or `MIXED_OR_INSUFFICIENT` when evidence is mixed or incomplete.

This is a comparison model, not a forecast. Sector leadership does not prove stock leadership, and stock strength does not prove fundamental quality.
