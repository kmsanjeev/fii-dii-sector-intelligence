# Institutional scope decision

Each response uses exactly one scope:

`DIRECT_STOCK_INSTITUTIONAL_DATA`, `DERIVED_OWNERSHIP_CONFIRMATION`, `DEAL_ACTIVITY_CONTEXT`, `MARKET_LEVEL_CONTEXT_ONLY`, or `NOT_SUPPORTED`.

The current local stock sources support deal activity and derived ownership context, not a direct daily FII/DII stock tape. Participant-flow scores are market-level only and are never described as stock-specific buying or selling. Deal labels from the source remain source labels and are not predictions.
