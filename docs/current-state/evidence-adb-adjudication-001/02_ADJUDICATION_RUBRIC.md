# Adjudication rubric

Rubric version: `R1-FROZEN-SOURCE-ONLY`.

The decision order is: preserve provider accuracy; exclude `time_unknown`; honor conflict/rectification flags; inspect documentary/source-note wording; use `dsc` only as structured context; and retain ambiguity as `UNRESOLVED_REVIEW_REQUIRED`. Direct/official documentary wording under dsc 1/51 qualifies Tier A. Explicit referenced documentary, news, biographical, autobiographical, or historical timed evidence under dsc 2/4/5 qualifies Tier B. Rodden rating alone never qualifies a VEDA tier.

No chart, Dasha, transit, house, feature, event outcome, or model result enters the adjudication.
