# Scale analysis

The frozen population produced 109 verified Tier A/B records from 120 (`90.83%`; Wilson 95% interval `84.33%–94.80%`). Applying that interval to the parent potential pool of 4,465 yields bounded scenarios of 3,765 conservative, 4,056 central, and 4,234 optimistic subjects. These are scenario projections only: selection bias and upstream source clustering prevent treating them as independent population estimates.

The largest source cluster is the Steinbrecher collection. Broader adjudication is therefore potentially valuable but must remain staged and cluster-aware.
