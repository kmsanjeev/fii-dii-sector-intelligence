# AI/ML non-training statement

VEDA does **not** use Astro-Databank data to train machine-learning models,
generative-AI models, foundation models, embeddings intended as AI training
data, or predictive AI. No ADB data is ingested into the VEDA RAG corpus.

AI-assisted software engineering, documentation, quality review, and research
administration are separate from training a model on ADB records. The current
activity performs no ML training, model fitting, feature scoring, prediction,
PRED-M4 activation, or production use.

Any future use remains conditional on provider permission, explicit terms, data
minimization, local access controls, retention limits, and a human review of
the permitted use. This statement is not a request to relax the provider's
no-AI-training policy.
