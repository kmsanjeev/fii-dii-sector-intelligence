## Verified policy

The current official export readme is versioned 29 March 2026 and records an
update on 30 March 2026: the ADB export was halted because of request overload.
It explicitly says that the contract and full-download ZIP were removed for the
duration of 2026 and that interested parties must use the large C sample. The
current export directory exposes the readme and current C-sample artifacts, but
no full-export ZIP.

The same readme records these serious-research expectations: a detailed project
description, researcher identity/qualification, tools and procedures, patterns
under investigation, and potential contribution. It also states that licenses
are not granted to non-researchers or for training AI systems.

The public ADB research tool distinguishes guest access (interface only, no
submitted queries), partial access (up to two filter cards), and full access (up
to five filters). The official route to full tool access is an Astrodienst Plus
subscription or special permission as a qualified researcher. The public pages
do not document an export API, bulk extraction permission, or programmatic
access contract for the research tool.
