# Privacy and Security Model

Minimum necessary data, pseudonymous research IDs, identity-vault separation,
least-privilege roles, encryption in transit/at rest/document/backup, audit
logging and deidentified exports are required. Sensitive originals should be
retained only for the minimum verification period, preferably as structured
metadata plus a source hash after adjudication. Legal, privacy, ethics,
incident-response and key-management reviews remain external gates.
