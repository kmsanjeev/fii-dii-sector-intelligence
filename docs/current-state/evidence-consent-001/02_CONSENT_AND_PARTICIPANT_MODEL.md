# Consent and Participant Model

Research keys are pseudonymous `PARTICIPANT_ID` values. Identity, if ever
needed, belongs in a separate identity vault. Consent is versioned and granular:
core research, birth verification, follow-up, document upload, aggregated
publication, deidentified sharing and future recontact are independent scopes.
Participant transitions include consent, birth verification, active follow-up,
pause and withdrawal states. Consent changes are not retroactive.
