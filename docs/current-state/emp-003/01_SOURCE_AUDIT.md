# Source Audit

Astro-Databank's Rodden guidance distinguishes AA/A/B data from C, DD and
unknown-source records; it also states that repeated references are not direct
source proof. The public-source search therefore produced no eligible case for
ingestion in this run. [Rating methodology](https://www.astro.com/astro-databank/Help%3ARR)

Public biographies can verify some dates and events, but without complete
source-lineaged birth time and chronological prediction cutoffs they remain
candidate or research-only material.
