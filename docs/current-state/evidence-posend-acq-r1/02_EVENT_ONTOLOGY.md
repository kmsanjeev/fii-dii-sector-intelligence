# Event ontology

The primary event is `FORMAL_PUBLIC_ROLE_END`: the effective end date of an
identifiable public or institutional role. The event date is not an
announcement date, resignation submission date, successor announcement,
ceremonial farewell or last appearance.

The eligible subtypes remain separate:

- `RETIREMENT_EFFECTIVE_DATE`
- `RESIGNATION_EFFECTIVE_DATE`
- `TERM_COMPLETION`
- `FORMAL_EMPLOYMENT_END`
- `OTHER_OBJECTIVE_POSITION_END`

The four acquired events are `TERM_COMPLETION` records. Generic career ends,
death endpoints and month/year-only retirement claims are excluded from the
primary non-mortality cohort.
