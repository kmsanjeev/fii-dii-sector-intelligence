# Acquisition policy

1. Freeze the existing governed birth frame before event discovery.
2. Order candidates by numeric ADB record ID, preserving the full denominator.
3. Search public/institutional documentary sources for formal roles, not
   charts, feature values or outcome fit.
4. Require an objective role identity, a DAY-precision formal start, a
   DAY-precision effective end, and a strong event source.
5. Prefer one official source plus independent corroboration where practical;
   copies of a shared source are not counted as independent evidence.
6. Exclude death as the first primary event family unless a separately governed
   mortality lane is authorized.
7. Stop when the current frame has been boundedly screened and remaining leads
   are weak, duplicative or biography-only.

The subject-level primary policy is
`FIRST_ELIGIBLE_FORMAL_ROLE_END_AFTER_ACQUISITION_FREEZE`. No astrology or
feature value participates in selection.
