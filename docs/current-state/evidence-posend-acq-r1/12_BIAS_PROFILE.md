# Bias profile

The exact-day pilot has four events from France, Belgium and Italy. All are
formal public roles, so public-figure and role-type selection bias is
intentional. All four birth inputs share the `STEINBRECHER_COLLECTION` birth
source cluster, which limits the conservative joint source-diversity bound to
1 even though event evidence spans three official publisher clusters.

The current frame has no India event candidate. This is reported as a frame
limitation; standards were not lowered to force geographic representation.
The corpus is not representative of the population, occupations, countries,
historical eras or birth-data availability.
