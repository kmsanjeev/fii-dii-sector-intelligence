# System Prompt Remediation

The core system identity is now neutral and additive. `GENERAL` and `RESEARCH`
receive neutral conversational framing; market, sector, stock, corporate,
AstroFinance and Kundli instructions remain domain hints. Explicit research is
not a synonym for “anything that did not match a keyword.”

Greeting and prompt-leak fallback language is also neutralized. The compliance
addendum remains applied to all intents without modification to its protected
safety boundaries.
