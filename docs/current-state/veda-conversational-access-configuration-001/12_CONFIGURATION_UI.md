# Configuration UI

Admin → Veda Access displays General Assistant, Market, Sector, Stock,
Corporate, Astrology, Research, Muhurta, Attachments, Reviewed Memory, MCP,
Repository Intake and Voice. Each row shows access, runtime, read-only maturity,
effective state, answer mode and reason. “Enable all available” restores the
versioned default profile. Protected safeguards are displayed as active with no
toggle.

The normal chat welcome and placeholders now expose broad conversation while
retaining discoverable specialist examples.
