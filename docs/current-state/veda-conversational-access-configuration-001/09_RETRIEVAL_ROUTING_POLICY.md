# Retrieval Routing Policy

Greetings, small talk and `GENERAL` turns do not automatically retrieve the
market intelligence corpus. This prevents irrelevant market context from
contaminating an ordinary answer. Attachments and explicit research remain
separate paths. Specialist and explicit `RESEARCH` turns retain the existing
unified/legacy retrieval governance and source transparency rules.

This is a routing policy, not a RAG corpus change. No unified RAG rebuild was
performed.
