# Evidence Source Tiers

| Tier | Meaning | Use |
|---|---|---|
| A | primary documentary birth and event provenance, independently reviewable | confirmatory candidate |
| B | strong institutional/structured source with explicit provenance | confirmatory only with review |
| C | referenced structured secondary source or one-sided corroboration | exploratory/feasibility |
| D | discovery-only, unsourced, ambiguous or synthetic | reject for inference |

Birth provenance and event provenance are scored independently. Source count is
not independent evidence when pages derive from the same biography or archive.
OGDB is an outcome-free mechanics/prevalence source; available birth time is
not the same as documentary verification.
