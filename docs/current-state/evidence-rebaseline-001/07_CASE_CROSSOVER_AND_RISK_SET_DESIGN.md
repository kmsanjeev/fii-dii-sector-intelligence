# Case-Crossover and Risk-Set Design

Primary estimand: within-subject change in exposure/feature state around a
pre-registered event date versus eligible control windows for the same subject.
Controls must be same-subject, outside the event window, exposure-eligible,
not overlapping another event, and reproducibly selected from a declared seed.

Target 1–5 controls per case; conditional logistic, exact conditional, or
permutation inference is selected before looking at outcomes. Multiple events
are retained with declared dependence handling. Year-precision POSEND records
cannot enter a day-level confirmatory risk set.
