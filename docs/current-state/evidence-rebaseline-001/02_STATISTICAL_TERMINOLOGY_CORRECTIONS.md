# Statistical Terminology Corrections

Use `no replicated signal detected at current N`, not “no effect”. Use
`insufficient power` only with a stated estimand, effect size, alpha, power,
design and exclusions. Do not call a prevalence audit a power calculation.

The supplied planner is a transparent two-proportion normal approximation for
sensitivity planning. It is not a case-crossover guarantee and never scores a
chart or changes PRED maturity.
