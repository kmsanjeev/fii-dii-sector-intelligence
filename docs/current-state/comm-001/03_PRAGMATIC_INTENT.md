# Pragmatic Intent

Intent is independent from conversation type and uses the extensible STD-003
contract: information, advice, explanation, reassurance, validation, venting,
social bonding, persuasion, challenge, tease, reflection, and learning.

The result retains literal meaning, likely pragmatic meaning, alternative
interpretation, ambiguity state, and evidence. Ambiguous messages such as
`I am fine` and bureaucratic double-talk remain uncertain; no private motive or
dishonesty is asserted.
