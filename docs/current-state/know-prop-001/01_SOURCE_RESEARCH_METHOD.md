# Source Research Method

Existing VEDA records were inspected before external research. External research then checked accessible classical-text repositories, a BPHS Chapter 15 translation page, and D4 technical references. Search snippets and anonymous/SEO pages were not treated as authority.

Inspected source families include BPHS repositories, Brihat Samhita/Jyotisha repositories, Saravali/Jataka Parijata/Phaladeepika listings, and D4 reference pages. Exact verse-level attribution is retained only where the inspected page exposes a passage; otherwise `REFERENCE_NOT_VERIFIED` remains.

No Sanskrit verse or translation was fabricated. No semantic RAG promotion occurred.
