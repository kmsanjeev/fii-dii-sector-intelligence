# Muhurta and Panchanga Routing

Natural-language routing now distinguishes factual Jyotish/Panchanga questions from electional requests.

| Request family | Route |
|---|---|
| “What is Panchanga?” | `ASTRO` |
| “What Panchanga is suitable for a ceremony?” | `MUHURTA` |
| Griha Pravesha, house entry, housewarming timing | `MUHURTA` |
| auspicious window, business opening, education commencement timing | `MUHURTA` |
| generic Nakshatra fact | `ASTRO` |

No Muhurta activity contract, recommendation rule, P032 fact, maturity state or production semantics changed. The change is routing only.
