# AstroFinance Routing

AstroFinance now requires astrology context plus market context. Market terms include stocks, NIFTY, Sensex, banking and other market identifiers; known symbols are recognized only in the astrology-plus-symbol context.

Plain stock requests remain `STOCK`, plain Jyotish remains `ASTRO`, and combined planetary/market requests remain `ASTRO_FINANCE`. This is a routing correction, not a change to AstroFinance calculations or predictive maturity.
