# Benchmark and Holdout

Development benchmark: 720 independent cases across all signs, all divisions and three within-division degrees, plus the 240-case full grid and boundary suite.

Holdout: 80 deterministic longitudes, including modality and wraparound coverage.

Division, modality, category-start, boundary, wraparound and method-attribution accuracy: `100%` against the independently encoded selected method. This validates implementation consistency with the qualified method; it does not validate the unresolved source mapping beyond the category-start rule.
