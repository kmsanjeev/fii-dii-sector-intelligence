# Legacy versus New Comparison

The legacy and selected methods agree for some movable-sign cases but diverge materially for fixed and dual signs, which was the original KNOW-SPIRIT-001 finding. The focused suite confirms the fixed Taurus representative and dual Gemini representative no longer use the legacy generic result. The legacy implementation remains callable only when explicitly requested as `general`; governed D20 chart construction uses the selected method.

The selected method’s sign progression is evidence-qualified rather than fully source-resolved because the inspected BPHS passage supplies starts and deity lists, not a complete modern sign-destination table.
