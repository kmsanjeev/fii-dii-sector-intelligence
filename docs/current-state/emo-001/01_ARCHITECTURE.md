# EMO-001 Architecture

`MESSAGE -> COMM-001/LANG-001 -> EMO-001 -> GROUP-001 (per speaker) -> COMM-002 -> EXISTING CHATENGINE`

EMO-001 is deterministic and local. It returns a structured emotional context
with primary/secondary signals, confidence, intensity, vulnerability,
interaction need, advice readiness, sensitivity, escalation risk, and evidence.
The structure is included in internal conversational guidance only; normal
users do not see diagnostic metadata.

Safety and trust precedence remains above emotional style. Emotional cues do
not alter Jyotisha facts, prediction confidence, high-stakes boundaries, RAG,
empirical state, or provider selection.
