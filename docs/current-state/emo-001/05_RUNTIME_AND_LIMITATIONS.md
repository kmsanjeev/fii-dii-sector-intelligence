# EMO-001 Runtime and Limitations

EMO-001 runs inside the existing ChatEngine analysis path with no routine
provider calls. Existing `/api/chat` compatibility and the group metadata path
remain intact in focused tests. The live backend capability endpoint remains
the production smoke endpoint.

The implementation is signal-based and conservative. Sarcasm, indirect emotion,
regional Hindi variation, and nuanced relational inference remain limited.
EMO-001 does not prove human-quality empathy; COMM-002 and GROUP-001 Founder
ratings remain pending in the separate blind evaluation package.
