# EMO-001 Relational and Group Context

GroupAnalysis now carries an emotional context per analyzed turn. The existing
speaker, chart subject, and addressee triad remains authoritative, so a
mother's worry about a daughter's chart is not assigned to the daughter.

Recent history provides a bounded emotional direction (`STABLE` or `SHIFTING`)
without creating permanent psychological profiles. Group climate is not
invented from a single participant's state; callers may synthesize it only from
the per-speaker records and existing GROUP-001 conflict state.
