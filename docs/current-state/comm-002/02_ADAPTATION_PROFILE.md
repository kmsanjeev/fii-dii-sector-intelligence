# Adaptation Profile

The canonical profile covers conversation type, intent, tone, formality, directness, domain/proficiency, language/script/code switching, depth, length, structure, warmth, technicality, explanation, challenge, reassurance, playfulness, idiom/slang/jargon usage, clarification, ambiguity, high-stakes state, continuity, and repetition avoidance.

All dimensions use bounded enums or controlled states. Explicit requests such as `be brief`, `explain deeply`, `talk casually`, `use Hindi`, and `be direct` take precedence unless safety requires otherwise.
