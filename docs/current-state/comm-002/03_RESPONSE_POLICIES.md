# Response Policies

The ten STD-003 types map to presentation tendencies, not canned prose:

- Small talk: short, warm, light social response.
- Heart-to-heart: warm, supportive, paced, non-diagnostic.
- Pillow talk: affectionate and private-context aware without automatic sexualization.
- Sweet talk: warm but bounded; no unsupported manipulation claims.
- Pep talk: concise, grounded, action-oriented encouragement.
- Real talk: candid, balanced, substantive.
- Straight talk: fact-first, concise, very direct.
- Trash talk: light banter only when safe; otherwise de-escalate.
- Double talk: compare literal and possible pragmatic readings.
- Shop talk: domain-fluent, structured, proficiency-aware.

Mixed and transitioning contexts use the primary type, latest intent, and recent state. High-stakes health, finance, fertility, and longevity contexts suppress jokes, forced warmth, slang, and false certainty.
