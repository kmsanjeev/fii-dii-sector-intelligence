# VEDA-KNOW-TIMING-002 — Implementability and Prevalence

## Implementability

- `IMPLEMENTABLE`: period sequence and interval boundaries only.
- `IMPLEMENTABLE_WITH_CONDITION`: narrow house-lord, Antardasha and
  Phaladeepika transit-conjunction primitives, provided all method inputs are
  available.
- `BLOCKED_BY_SOURCE`: generic significator, relationship, transit,
  obstruction and termination extensions.

No production implementation was added. The research registry supports future
binary `PRESENT`, `ABSENT` and `INDETERMINATE` states without LLM judgment.

## Prevalence

Audited primitives: `0`.

The available OGDB data is not a complete timed-chart population for house/lord
and transit computation: birth records lack resolved coordinate/timezone/chart
inputs. The existing 25-case chart snapshot is historical empirical material,
not an independent outcome-free prevalence population for this activity. No
event outcomes were inspected and no substitute prevalence estimate was made.

No primitive is therefore classified as `TOO_COMMON`, `EMPIRICALLY_USEFUL_RANGE`,
`LOW_PREVALENCE`, `NEAR_ZERO`, or `UNREACHABLE` yet.
