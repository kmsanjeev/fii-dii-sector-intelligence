# VEDA-KNOW-TIMING-002 — Primitive Research Method

The unit of research is one deterministic relationship, not a finished event
rule. Each primitive records source lineage, doctrine level, event-family
scope, deterministic states, implementation state and empirical readiness.

Required separation:

`NATAL_PROMISE` → `DASHA_ACTIVATION` → `TRANSIT_TRIGGER` → `EVENT_TIMING`

Obstruction and termination remain separate. A source statement that a Dasha
may produce a result is retained only at that textual scope; it is not expanded
to every event represented by a planet or house.

The authoritative machine-readable registry is
`VEDA_TIMING_PRIMITIVE_REGISTRY` in
`docs/current-state/know-timing-002/04_timing_primitive_registry.json`.
