# Property Domain Model

The canonical result separates property potential, acquisition, ownership, residence stability/change, land, constructed property, self-occupied/investment context, inheritance, sale, construction, renovation, expenditure, debt, dispute, domestic comfort, timing, confidence, conditions, alternatives, contradictions, missing data and trust state.

Ownership is not residence. Acquisition is not ownership. Purchase is not inheritance. Sale is not loss. Residence change is not foreign settlement.
