# P029 Architecture

`PropertySynthesisEngine` consumes existing chart facts and optional P022 wealth context. The pipeline is D1/property facts -> optional validated Varga context -> Dasha activation -> Transit timing -> P027-style evidence/contradiction trace. P027 remains the reasoning owner; ChatEngine remains the response owner.

The property registry explicitly blocks property price prediction, ROI, financial advice, legal advice and fatalistic ownership claims. Routine provider calls added: 0.
