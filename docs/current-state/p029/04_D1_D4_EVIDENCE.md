# D1 and D4 Evidence

The existing runtime supplies D1 houses/lords and may surface D4 calculations in broader profiles. A validated P029 D4 interpretation method was not found. P029 therefore returns `D4_NOT_VALIDATED` or `D4_NOT_IMPLEMENTED_OR_UNAVAILABLE`, records missing data, and continues conservatively through D1 facts. D4 is never allowed to override D1 by assumption.
