# Export Schema Audit

Observed XML `export_format=160715`, `update_since=Tue Jul 28 20:06:49 2026
UTC`, 6,036 `<adb_entry>` elements.

Observed top-level entry groups: `public_data`, `text_data` and
`research_data`. Public fields include ADB ID, name, gender, Rodden rating,
birth date, time, place, country, timezone abbreviation and collector/editor/
biographer fields. Text fields include source notes, short biography, ADB link
and optional Wikipedia link. Research fields include categories,
relationships and events.

The source provides birth/event dates and event labels, but event rows are
embedded ADB research data and are therefore discovery evidence only until
independently corroborated. Names and free text were not copied into committed
derived artifacts.
