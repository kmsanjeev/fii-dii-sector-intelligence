# Source Clusters and Bias

The export exposes collector/editor/biographer fields and source notes, but no
reliable independent upstream-source cluster was established in this bounded
audit. Repeated ADB notes and copied biography text are not independent
confirmations. The parser does not count them as such.

The sample is the C-name subset, not a random population. It is suitable for
schema, parser, source-field and pipeline feasibility. It is not authorized for
full-database prevalence, population inference or generalization of Tier yield.
