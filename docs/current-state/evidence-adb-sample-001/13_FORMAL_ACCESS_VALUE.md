# Formal Access Value

Decision: `FORMAL_ACCESS_CONDITIONAL_VALUE`.

The free sample materially demonstrates parser/schema feasibility and exposes
birth fields, ratings, source notes and event structures. It does not expose
enough independently verified birth-document lineage to map A/AA to VEDA Tier
A/B. The sample also shows large event volume, but ADB event rows remain
`ADB_EVENT_DISCOVERY_ONLY` until independent corroboration.

Full/research access would have value only if it supplies permitted provenance,
source lineage and licensed research fields beyond the free sample. A formal
request remains a human action and was not submitted.
